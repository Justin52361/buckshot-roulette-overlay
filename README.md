# Buckshot Roulette // Tactical Overlay & DLL Injector

A tactical on-screen game overlay and DLL injection tool built in **C# (.NET)** for **Buckshot Roulette** (singleplayer).

Displays a real-time HUD on top of the game showing the exact count of **Live** and **Blank** rounds remaining in the shotgun, win probabilities, shot history, and tactical advice.

---

## Features

- **On-Screen Game Overlay**:
  - Automatically snaps and anchors to the `Buckshot Roulette` window.
  - Custom dark cyber-noir CRT theme matching the game's aesthetic.
  - **Live Rounds Counter**: Glowing crimson red shell indicators & count.
  - **Blank Rounds Counter**: Glowing electric cyan shell indicators & count.
  - **Dynamic Probability Gauge**: Real-time ratio and percentage of Live vs Blank on the next trigger pull.
  - **Tactical Strategy Hints**:
    - `100% LIVE -> SHOOT DEALER NOW!`
    - `100% BLANK -> SHOOT SELF (FREE EXTRA TURN!)`
    - `FAVORABLE (75% LIVE) -> HIGH VALUE TO SAW & SHOOT DEALER`
    - `DEFENSIVE (75% BLANK) -> SAFER TO SELF-SHOOT OR USE BEER`
    - `50/50 COIN FLIP`
  - **Shot Sequence History Strip**: Shows past rounds shot/ejected in the active load.
  - **Click-Through Mode (`F4`)**: Makes the overlay transparent to mouse clicks (`WS_EX_TRANSPARENT`), allowing uninterrupted gameplay and shooting while the overlay remains visible on top.

- **Native 64-bit DLL Injection Engine**:
  - Automatically locates `Buckshot Roulette.exe` process (PID, Window Handle, x64 architecture).
  - One-click DLL injection into the game using standard Windows APIs (`OpenProcess`, `VirtualAllocEx`, `WriteProcessMemory`, `CreateRemoteThread`, `LoadLibraryW`).
  - Diagnostic event logging with real-time feedback.
  - Automatically generates and writes the 64-bit `BuckshotHook.dll` binary into the game directory.

- **Zero-Input Automated Round & Shot Tracking**:
  - **Auto-Detect Round Reveals**: Uses hardware-accelerated Windows Media OCR on the dealer's announcement strip (`"X LIVE ROUNDS. Y BLANK(S)."`). Automatically initializes and resets the HUD with the exact counts with **zero user input**.
  - **Auto-Deduct Fired Shells**: Continuously monitors the shotgun chamber state in Godot 4 process memory and synchronizes with muzzle flash visual detection to automatically deduct live and blank shells as the round progresses.
  - **Auto-Reset on New Loads**: When all shells are expended or a new round begins, the tracker automatically detects the new load announcement, resets counts, and begins tracking the next round seamlessly.

- **Global In-Game Hotkeys**:
  - `F4`: **Toggle Click-Through** (Locks/unlocks mouse interaction through overlay)
  - `F8`: **Reset Round** (Resets counts to the initial load of the round)
  - `F9`: **Hide / Show Overlay** (Toggles overlay visibility)

## Quick Start Guide

### 1. Launching the Tool
Double-click `run.bat` (or execute `.\dist\BuckshotOverlay.exe`).

### 2. Playing Buckshot Roulette
1. Start **Buckshot Roulette** (Steam or itch.io).
2. In the **Buckshot Roulette Control Center**:
   - The status bar will turn green: `BUCKSHOT ROULETTE RUNNING! (PID: xxxx)`.
   - Click **INJECT DLL INTO GAME** to inject `BuckshotHook.dll` into the game process.
   - Click **SHOW OVERLAY** to display the HUD (it will automatically anchor to the top-right of your game screen).
3. The overlay will automatically track rounds and shots seamlessly using the OCR & memory engine.
4. While playing:
   - Press **`F4`** to enable **Click-Through Mode** so your clicks pass directly through to the shotgun and items.
   - Press **`F8`** to restart the current round count if needed.
   - Press **`F9`** to hide or show the overlay HUD.
